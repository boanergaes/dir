# Dir-Collaboration-Platform

A real-time collaboration platform for developers built with React, Express, and Socket.io. Import GitHub repos into workspaces featuring instant file navigation, multi-channel chat, deep repository analytics, and live GitHub Actions tracking.

## Project Structure

- `frontend/`: React + Vite SPA
- `backend/`: Node.js + Express API
- `Screenshots/`: UI demonstration assets

## Setup

Refer to the README files in `frontend/` and `backend/` for setup instructions.
